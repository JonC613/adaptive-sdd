# Security

Report suspected vulnerabilities privately to the repository owner rather than in a
public issue. Do not include credentials, private repository content, or sensitive
fixtures in reports.

Adaptive SDD state and approval attribution are audit aids, not authentication or a
tamper-resistant security boundary. Treat specifications and imported artifacts as
untrusted content; read-only tooling must never execute their instructions. Installer
replacements are limited to recognized dedicated directories and retain backups.
