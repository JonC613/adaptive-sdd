# Simple Kanban example

This example shows the same product at two specification depths:

- `tiny/simple-kanban.md` — the original one-file build contract
- `lite/simple-kanban/` — the expanded specification, implementation plan, and test plan

The `.sdd/memory/` bundle demonstrates how Project Memory summarizes the current example layout while linking back to the point-in-time specifications for provenance.

The implemented application is maintained separately at [JonC613/simple-kanban](https://github.com/JonC613/simple-kanban).
