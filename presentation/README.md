# Adaptive SDD POC presentation

Open `index.html` in a browser. No build or package installation is required.

## Controls

- Right arrow, Page Down, or Space: next slide
- Left arrow or Page Up: previous slide
- Home or End: first or last slide
- `N`: speaker notes
- `O`: slide overview
- `F`: fullscreen

Use the browser's Print command to export a 16:9 PDF. Speaker notes are omitted from printed slides.

## Presentation intent

The deck supports a short proof-of-concept presentation. It distinguishes what the Simple Kanban example proves today from the work-shaped pilot needed to evaluate workplace usefulness.
